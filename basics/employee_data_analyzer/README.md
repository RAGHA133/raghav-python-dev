# Employee Data Analyzer

### 🔹 Description:
A basic Python project to help you practice key programming concepts by working on a simple, real-world dataset of employees.


- Reads from `employees.csv`
- Filters employees by department
- Calculates average salary
- Shows highest paid employee


- Variables, Strings
- Lists & Dictionaries
- File Handling
- Functions
- Conditionals & Loops

python analyzer.py
